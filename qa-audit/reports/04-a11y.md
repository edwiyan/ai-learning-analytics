## Recurring Violations (Root-Cause Analysis)

### 1. `color-contrast` — Appears on 23/28 pages (GLOBAL)
**Severity:** Serious (WCAG 1.4.3)  
**Root cause:** `Layout.jsx` sidebar uses `text-gray-400` (#9ca3af) on white background — contrast ratio ~3.1:1, below WCAG AA 4.5:1 for body text.  
**Affected elements:**
- `Layout.jsx:126` — `<p className="text-xs text-gray-400 capitalize">` — role label under user name
- `Layout.jsx:176` — `<p className="text-xs text-gray-400 truncate">` — email in sidebar footer
- `Pagination.jsx:20` — `<p className="text-xs text-gray-400">` — "1–10 of 37" pagination info
- `StatCard.jsx:13` — `<p className="text-xs text-gray-400 mt-1">` — subtitle on stat cards  
**Fix:** Change `text-gray-400` → `text-gray-500` (contrast ~4.6:1) on all these body-text elements. (`text-gray-400` is acceptable only for decorative elements, not informational text.)

### 2. `button-name` — Appears on 6 pages (Pagination, Login)
**Severity:** Critical (WCAG 4.1.2)  
**Root cause A — Pagination.jsx:** Prev/Next buttons contain only SVG icons with no text or `aria-label`.
```jsx
// Line 25-32 and 47-54 — both buttons missing aria-label
<button disabled={page === 1} onClick={() => onChange(page - 1)}
  className="p-1.5 rounded-lg ...">
  <svg ...>...</svg>   {/* No aria-label anywhere */}
</button>
```
**Root cause B — Login.jsx:** Password visibility toggle button (line 78–97) is an icon-only button with no `aria-label`.  
**Fix A:** Add `aria-label="Previous page"` and `aria-label="Next page"` to `Pagination.jsx` buttons.  
**Fix B:** Add `aria-label={showPassword ? "Hide password" : "Show password"}` to `Login.jsx` toggle button.

### 3. `role-img-alt` — Appears on 4 pages (Chart pages)
**Severity:** Serious (WCAG 1.1.1)  
**Root cause:** Chart.js renders `<canvas>` elements with `role="img"` automatically, but without an `aria-label` or `aria-describedby`. Screen readers announce "image" with no context.  
**Affected pages:** `/admin`, `/instructor`, `/my-courses`, `/student` (when course selected)  
**Fix:** Wrap each Chart.js component in a `<figure>` with `aria-label` describing the chart. Alternatively, pass `aria-label` via Chart.js dataset options.  
Example:
```jsx
<div role="img" aria-label="Risk distribution chart: At-Risk 2, On-Track 4, Excelling 1">
  <Doughnut data={...} />
</div>
```

### 4. `select-name` — Student dashboard (Critical)
**Severity:** Critical (WCAG 1.3.1)  
**Root cause:** `StudentDashboard.jsx:219` — `<select>` has no `<label>` or `aria-label`.
```jsx
<select   {/* ← no aria-label, no id, no associated <label> */}
  value={selectedCourse ? courseKey(selectedCourse) : ""}
  ...
>
```
**Fix:** Add `aria-label="Select course"` to the `<select>` element.

### 5. `label` — Audit logs date filter (Critical)
**Severity:** Critical (WCAG 1.3.1)  
**Root cause:** `AuditLogsPage.jsx:186–190` — two `<input type="date">` elements have no associated `<label>`.
```jsx
<input type="date" value={from} .../>   {/* ← no aria-label */}
<input type="date" value={to} .../>     {/* ← no aria-label */}
```
**Fix:** Add `aria-label="Filter from date"` and `aria-label="Filter to date"` to both inputs.

### 6. `document-title` — 5 pages (Serious)
**Severity:** Serious (WCAG 2.4.2)  
**Root cause:** `index.html:7` — `<title>frontend</title>`. The SPA never updates `document.title` per page.  
**Fix:** Add `document.title = "Page Name | AILAS"` in each page component's `useEffect`, or use a `<Helmet>` wrapper.  
Minimum fix: change `<title>frontend</title>` to `<title>AILAS — Learning Analytics System</title>` in `index.html`.

## New Defects Found

### DEF-14 — P1: Unlabeled interactive elements on 6 pages (WCAG critical)
**Area:** `frontend/src/components/Pagination.jsx`, `frontend/src/pages/Login.jsx`, `frontend/src/pages/StudentDashboard.jsx`, `frontend/src/pages/AuditLogsPage.jsx`  
**Evidence:** axe reports `button-name` (critical) on 6 pages, `select-name` (critical) on student dashboard, `label` (critical) on audit logs.  
**Impact:** Screen reader users cannot identify icon buttons, the course selector, or date filters by name.  
**Fix:**
```jsx
// Pagination.jsx — prev/next buttons:
<button aria-label="Previous page" ...>
<button aria-label="Next page" ...>

// Login.jsx — password toggle:
<button aria-label={showPassword ? "Hide password" : "Show password"} ...>

// StudentDashboard.jsx — course selector:
<select aria-label="Select course" ...>

// AuditLogsPage.jsx — date filters:
<input type="date" aria-label="From date" ...>
<input type="date" aria-label="To date" ...>
```

---

### DEF-15 — P1: Chart.js canvases have no alt text (WCAG serious across 4+ pages)
**Area:** All pages with charts — Admin dashboard, Instructor dashboard, Student My Courses, Student Dashboard  
**Evidence:** axe `role-img-alt` (serious) on canvas elements; screen reader announces "image" with no description.  
**Impact:** Blind users cannot access any of the risk, performance, or analytics visualizations.  
**Fix:** Wrap each chart in a `<figure>` element with an `aria-label` summarizing the data, or use Chart.js's built-in `aria-label` dataset option.
```jsx
<figure aria-label="Risk distribution: At-Risk 2, On-Track 4, Excelling 1">
  <Doughnut data={chartData} />
</figure>
```
Minimum fix: Add `aria={{ label: description }}` to Chart.js component props.

---

### DEF-16 — P2: Global `text-gray-400` fails WCAG AA contrast (23/28 pages)
**Area:** `frontend/src/components/Layout.jsx`, `Pagination.jsx`, `StatCard.jsx`  
**Evidence:** axe `color-contrast` (serious) on all pages containing Layout. `text-gray-400` (#9ca3af) on white gives 3.1:1 — below WCAG AA 4.5:1 minimum.  
**Fix:** Replace informational `text-gray-400` with `text-gray-500` globally in Layout.jsx, Pagination.jsx, StatCard.jsx. Keep `text-gray-400` only for decorative/placeholder elements.

---

### DEF-17 — P2: Page `<title>` is always "frontend" (all pages)
**Area:** `frontend/index.html:7`  
**Evidence:** `<title>frontend</title>` — never changes across page navigation. WCAG 2.4.2 requires each page to have a descriptive title.  
**Fix (minimum):** Change to `<title>AILAS — Learning Analytics System</title>` in `index.html`.  
**Fix (complete):** Add `document.title = "Dashboard | AILAS"` (etc.) in each page's `useEffect`.

---

### DEF-18 — P3: No skip-navigation link
**Area:** `frontend/src/components/Layout.jsx`  
**Evidence:** Keyboard users must tab through the full sidebar navigation on every page before reaching main content. No "Skip to main content" anchor exists.  
**Fix:** Add a visually-hidden skip link as the first focusable element:
```jsx
<a href="#main-content" className="sr-only focus:not-sr-only focus:absolute focus:top-2 focus:left-2 z-50 ...">
  Skip to main content
</a>
```
